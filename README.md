# Spine Runtime for Axmol v3

This repository provides the Spine runtime integration for **Axmol v3**.  
For **Axmol v2**, please visit: [spine-axmol2](https://github.com/axmolengine/spine-axmol2).

---

## 📦 Usage

1. Remove all files under `axmol/extensions/spine`.
2. Switch to branch `spinexx`.
3. Copy the folder `spine-axmol/spine` into `axmol/extensions/spine`.

---

## 🎯 Supported Spine Versions
- 4.3
- 4.2
